# Fluxo do GitHub

```text
main
└── feature/minha-tarefa
    └── Pull Request
        └── revisão
            └── merge
```

## Exemplo pelo GitHub Desktop

1. Faça `Fetch origin`.
2. Troque para `main` e use `Pull origin`.
3. Crie uma branch com nome claro, como `feature/tela-catalogo`.
4. Faça commits pequenos e descritivos.
5. Use `Push origin`.
6. Abra um Pull Request e peça revisão.

Evitem que duas pessoas editem o mesmo arquivo grande ao mesmo tempo. Dividam por tarefa, não apenas por linguagem.
